# Weekly Review Workflow

## Procedure

1. Read `docs/CONTEXT.md`, the latest handoff, and `docs/weekly-review.md`.
2. Check active rows in `data/application-crm.csv`.
3. Find candidates with missing evidence, stale last-checked dates, or unclear next actions.
4. Rebalance the portfolio across field and risk tier.
5. Identify the next 3-5 concrete tasks.
6. Write a weekly review note from `templates/weekly-review.md`.

## Done Definition

- Every priority candidate has a next action.
- Every outreach item has a status.
- Every urgent deadline has been checked against an official page.
- New risks are visible in the CRM or weekly review note.

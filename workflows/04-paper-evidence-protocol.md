# Paper Evidence Protocol

Adapted from paper-search-mcp and PaperPilot style workflows.

## Goal

Use recent publications as evidence for advisor fit, not as a generic literature review.

## Search Plan

1. Start with the faculty name and official profile.
2. Search recent papers by author identity, not just name string.
3. Cross-check with at least one bibliographic database.
4. Deduplicate by title, DOI, venue, and year.
5. Keep only papers that explain advisor fit or risk.

## Source Suggestions

- CS: DBLP, Semantic Scholar, Google Scholar, OpenAlex, arXiv, conference pages.
- Statistics: arXiv, Google Scholar, OpenAlex, Crossref, journal pages, NSF awards.
- Biostatistics: PubMed, PMC, Europe PMC, NIH RePORTER, medRxiv, bioRxiv, lab pages.

## Inclusion Rules

Include papers that are:

- Recent enough to show current direction.
- Connected to applicant interests or methods.
- Useful for outreach specificity.
- Useful for identifying collaborators, students, or grants.

## Exclusion Rules

Exclude papers that are:

- Not the same author.
- Too old to show current advising direction unless foundational.
- Irrelevant to the applicant's stated profile.
- Unsupported by accessible metadata.

## Output

Use an evidence table with title, year, venue, source, relevance, and what it proves.

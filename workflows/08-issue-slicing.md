# Issue Slicing Workflow

Adapted from the `to-issues` pattern.

## Goal

Turn broad advisor-search work into small, trackable GitHub issues.

## Good Issue Shapes

- Search one department or program.
- Deep-dive 5 faculty from one longlist batch.
- Audit funding for one shortlist group.
- Draft outreach for one A-tier candidate.
- Verify one uncertain admissions route.

## Issue Template

Title: `[Advisor Search] <school/program/topic>`

Body:

- Goal:
- Scope:
- Inputs:
- Required sources:
- Output files to update:
- Done definition:
- Risks / unknowns:

## Rule

Each issue should produce a visible artifact: CSV update, dossier, shortlist report, handoff, or outreach draft.

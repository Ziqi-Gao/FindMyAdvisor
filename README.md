# FindMyAdvisor

A Codex-first workflow repository for 2027 Fall North American PhD applications in CS, Statistics, and Biostatistics.

The repository is organized around advisor discovery and evidence-backed due diligence. SOP writing is intentionally secondary.

## Core Loop

1. Clarify applicant profile and research targets.
2. Build a faculty longlist from official and bibliographic sources.
3. Screen weak or stale fits.
4. Create evidence-backed professor dossiers.
5. Check funding, admissions path, and availability signals.
6. Audit claims before outreach.
7. Track shortlist, outreach, replies, and decisions.

## Repository Map

- `.codex/skills/` - project-scoped skills for Codex.
- `workflows/` - reusable advisor-search workflows adapted from external projects.
- `templates/` - profile, report, dossier, outreach, and tracking templates.
- `schemas/` - lightweight JSON schemas for structured advisor data.
- `data/` - CSV trackers and local working datasets.
- `docs/` - profile context, decision notes, handoffs, and source policy.

## Safety Defaults

- Use public sources only.
- Separate facts, inferences, and unknowns.
- Never treat anonymous reputation as fact.
- Never send outreach automatically.
- Require human review before any email is used.
- Prefer official, department, lab, admissions, bibliographic, NSF, and NIH sources.

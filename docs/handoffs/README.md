# Handoffs

Write a handoff after every substantial research session.

## Naming

Use `YYYY-MM-DD-short-topic.md`.

Examples:

- `2026-06-08-initial-skill-install.md`
- `2026-07-12-cmu-stat-shortlist.md`

## Required Sections

- Goal of the session.
- Sources checked.
- Advisor candidates added or changed.
- Strong fits found.
- Weak fits removed and why.
- Unknowns that still matter.
- Files updated.
- Recommended next action.

## Rule

A future session should be able to resume from the latest handoff without rereading the entire repository.

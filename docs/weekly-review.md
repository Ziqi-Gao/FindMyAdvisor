# Weekly Review

Run this once per week during active search months.

## Checklist

- New faculty added this week.
- Candidates upgraded or downgraded.
- A-tier candidates missing dossiers.
- Dossiers missing source URLs or source dates.
- Outreach drafts waiting for human approval.
- Emails needing follow-up.
- Programs with deadline or requirement risk.
- Duplicate faculty records.
- Candidates with stale last-checked dates.

## Output

Use `templates/weekly-review.md` and update:

- `data/application-crm.csv`
- `data/faculty-index.csv`
- `data/evidence-matrix.csv`
- `data/outreach-log.csv`

## Cadence

- Weekly: CRM cleanup and next actions.
- Every two weeks: dossier quality audit.
- Monthly: portfolio balance across CS, Statistics, Biostatistics, reach, target, and safer programs.

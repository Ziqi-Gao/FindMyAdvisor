# Advisor Composite Scoring Model

Date: 2026-06-10  
Version: v0.1  
Purpose: produce a ranked advisor master table that combines positive advisor fit with applicant-specific admission difficulty penalties.

## Scope

This model ranks the currently tracked advisor-program pairs in `data/advisors.csv`. It is a decision-support model, not an admission-probability model.

The model uses only the evidence already recorded in the local CRM:

- `data/advisors.csv`
- `data/faculty-index.csv`
- `data/evidence-matrix.csv`
- `data/program-difficulty.csv`

If a candidate does not yet have an audited difficulty row, the table uses a clearly marked heuristic difficulty estimate. Those rows should be audited before final application decisions.

## AHP-Lite Structure

The model uses an AHP-style weighted hierarchy. Weights reflect the current project objective: find strong 2027 Fall PhD advisor fit while avoiding an application list dominated by ultra-reach programs.

### Positive Score

Positive score is on a 0-100 scale.

| Criterion | Weight | Meaning |
|---|---:|---|
| Research alignment | 0.35 | Match to RAPTOR, LLM interpretability/control/reliability, high-dimensional statistical learning, and the applicant's actual evidence. |
| Paper-specific hook | 0.18 | Whether there is a concrete recent paper/project hook, not just generic topical similarity. |
| Evidence quality | 0.14 | Source quality, recency, public pages, papers, lab/student visibility, and dossier/paper-card depth. |
| Funding/lab vitality | 0.10 | Grants, awards, active lab, current students, funded openings, or other capacity-adjacent signals. |
| Admissions actionability | 0.13 | Clear route, list-faculty instruction, recruiting/openings statements, and contact-policy clarity. |
| Portfolio value | 0.10 | Strategic value after considering reach/target balance and cluster redundancy. |

Formula:

```text
positive_score =
  10 * (
    0.35 * research_alignment_10
  + 0.18 * paper_hook_10
  + 0.14 * evidence_quality_10
  + 0.10 * funding_lab_10
  + 0.13 * admissions_actionability_10
  + 0.10 * portfolio_value_10
  )
```

### Negative Score

Penalty base is on a 0-10 scale. It is then multiplied by 3 so the maximum penalty is 30 points.

| Criterion | Weight | Meaning |
|---|---:|---|
| Program/advisor difficulty | 0.75 | Applicant-specific difficulty from `data/program-difficulty.csv`, or a marked heuristic estimate when missing. |
| Capacity uncertainty | 0.15 | Fall 2027 slot uncertainty, junior/small lab risk, committee route, limited email response, sabbatical, or no explicit opening. |
| Risk penalty | 0.10 | Weak fit, stale evidence, unclear route, cluster crowding, no-current-student signal, or availability warnings. |

Formula:

```text
penalty_score = 3 * (
    0.75 * difficulty_10
  + 0.15 * capacity_uncertainty_10
  + 0.10 * risk_penalty_10
)
```

### Composite Score

```text
composite_score = positive_score - penalty_score
```

Higher is better.

## Interpretation

| Composite Band | Meaning |
|---|---|
| 60+ | Top priority under current evidence. Usually strong fit plus manageable difficulty or unusually strong hook. |
| 55-59.9 | Strong candidate. Worth dossier, paper-card, or route audit. |
| 50-54.9 | Plausible candidate. Keep if portfolio needs this area/school/difficulty tier. |
| 45-49.9 | Secondary candidate. Needs a stronger paper hook or clearer route. |
| Below 45 | Low priority under current evidence; revisit only if strategy changes. |

## Important Limits

- The score is not an admission probability.
- Funding signals do not guarantee available slots.
- A high score does not authorize outreach.
- Rows with heuristic difficulty should not drive final application decisions until official route/capacity is audited.
- Cluster redundancy is only lightly modeled; crowded clusters still need manual review.

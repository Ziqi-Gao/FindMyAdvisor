# Grill With Docs

Adapted from `mattpocock/skills`.

## Procedure

1. Read all available applicant materials and `docs/CONTEXT.md`.
2. Ask pointed questions about unclear projects, methods, results, constraints, and research direction.
3. Extract advisor-search keywords from actual evidence.
4. Identify weak or missing profile elements that could affect school selection.
5. Update `docs/CONTEXT.md` with facts, inferences, and unknowns.
6. Only then start or refine advisor discovery.

## Output

- Updated applicant context.
- Search keywords by field.
- Missing evidence list.
- Suggested next advisor-search batch.

# Issue Slicer

Adapted from `mattpocock/skills` to-issues pattern.

## Procedure

1. Read the current goal and `workflows/08-issue-slicing.md`.
2. Split work by school, department, field, search batch, funding audit, or outreach candidate.
3. Make each issue produce a concrete artifact: CSV update, dossier, shortlist report, funding check, outreach draft, or handoff.
4. Include source types and done definition.
5. Avoid giant issues like "find all advisors".

## Output

Produce issue titles and bodies ready to paste or create through GitHub.

# Academic Research Suite

Adapted from Codex academic research skill collections and co-researcher style workflows.

## Use After Advisor Fit Work

This is not the first skill for finding supervisors. Use it when a research cluster or professor shortlist already exists.

## Procedure

1. Define the research cluster or advisor group.
2. Build a small, high-quality bibliography.
3. Synthesize methods, datasets, questions, and gaps.
4. Map applicant projects to the cluster.
5. Produce positioning notes for advisor fit, SOP, or future proposal writing.

## Output

- Cluster summary.
- Key papers table.
- Faculty comparison.
- Applicant positioning.
- Missing reading list.

# Program Requirements Audit

## Procedure

1. Use official program and graduate school pages first.
2. Record deadline, timezone, degree, department, application URL, faculty page URL, and admissions path.
3. Check faculty contact policy before recommending outreach.
4. Record GRE, English test, recommendation, statement, writing sample, fee waiver, and funding rules.
5. Save source URLs and last-checked date.
6. Update `data/programs.csv` and `data/application-crm.csv`.

## Output

- Program requirement summary.
- Unknowns and source gaps.
- Application feasibility risk.
- Next action.

## Rule

Application requirements change. Always include the exact checked date and official URL.
